# Synthetic fixtures

Generated by the test suite's writers (`packages/disasm/test/writers/`, and
`packages/emu/test/unit/label-sample.js` for `label-file/`) via
`pnpm fixtures`. Do not edit by hand: `packages/disasm/test/fixtures.test.ts`
and `packages/emu/test/unit/label-file.test.js` fail if a committed file
differs from what the writer produces.

- `cmd/` — one .CMD load module per loader rule in the project plan.
- `bas/` — tokenized Level II BASIC programs saved from different base addresses.
- `label-file/` — a label and coverage file (`docs/label-format.md`) written by
  the emulator from a synthetic session; the disassembler's label-file tests
  read it.
